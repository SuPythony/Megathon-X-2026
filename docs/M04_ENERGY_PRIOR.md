# M04 energy-intensity prior — model card

Generated by `scripts/model_card_energy_prior.py` from `artifacts/m04_energy_prior/v2/`. Interactive report: `eval/reports/m04/report.html`. Plan: `docs/M04_PLAN.md`.

## What it is

Predicts a home's annual **electricity** and **gas** intensity (kWh/m²/yr) from the fields a GreenTwin `Property` carries, as a full predictive `Distribution` plus additive EBM contributions (`EnergyPrior` contract). It is the prior for homes without meters and the centre of the Bayesian calibration (M09). It never produces customer savings; the physics twin does.

## Data

- **Source:** DESNZ NEED anonymised data 2025, 4M-row sample (OGL v3).
- **Target:** mean of valid (flag `V`) readings 2021–2023 ÷ representative floor area of the NEED band {'1': 40.0, '2': 75.5, '3': 125.5, '4': 175.5, '5': 250.0} m² (bands only in NEED).
- Gas: gas-heated homes only, weather-corrected by DESNZ. Electricity: all homes, not weather-corrected.
- **Split:** by property, stratified on PROP_TYPE × PROP_AGE_BAND × FLOOR_AREA_BAND × REGION × MAIN_HEAT_FUEL; 60% train / 10% tune / 10% calibration / 20% test, seed 42.
- **Excluded:** `COUNCIL_TAX_BAND` (not in the Property contract (unavailable at prediction time)).
- 20% of training homes have IMD masked (`imd_mask_frac=0.2`) so 'unknown' is learnt.

## Using it

- Python: `from greentwin.models.energy_prior import energy_prior` → `EnergyPrior`; `greentwin.models.prior_update.update_with_meters(load_default(), prop, usage)` → prior/posterior per fuel.
- CLI: `uv run python -m greentwin.models.energy_prior contracts/examples/SH2_property.json --usage contracts/examples/SH2_usage_2025.json`.
- HTTP: `greentwin.api.energy_prior.router` (mount with `app.include_router(router)`): `POST /m04/energy-prior`, `POST /m04/energy-prior/update`, `GET /m04/health`. Standalone: `uv run uvicorn greentwin.api.energy_prior:app --port 8040`.
- Monitoring: `uv run python scripts/check_energy_prior.py` (10 checks: artefacts, contract, additivity, monotonicity, Bayesian update, quality thresholds, staleness, HTTP round-trip, fresh re-score of held-out homes); each pass is appended to `artifacts/m04_energy_prior/v2/monitor.log`.
- Repo notes: the trained `model.pkl` (≈250 KB) is committed despite the `*.pkl` ignore rule so the API and demo work without a 1 GB download and retraining; `uv.lock` is not committed (the repo does not track one).

## Limits

- Per-home R² is bounded by behaviour that no NEED field records; the ceiling quantifies this.
- NEED floor area is banded; intensity uses band midpoints, with a fitted within-band area elasticity.
- `MAIN_HEAT_FUEL` is gas vs not-gas only: electric-, oil- and LPG-heated homes share one group.
- LI/CWI flags mean 'installed under a government scheme since 2000'; mapped from Property fabric as a proxy.
- Year-to-year noise is fitted on weather-corrected gas; raw meter gas gets an extra labelled weather term.
